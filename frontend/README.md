# Chronicle frontend

React and Vite client for the local Chronicle FastAPI service.

From this folder, install dependencies with `npm install`, then start the development server using `npm run dev -- --host 127.0.0.1`. The client uses `http://127.0.0.1:8000` for the API; start the backend from the repository root before opening `http://127.0.0.1:5173`.

For the complete case workflow, API, validation, and limitations, see the [project README](../README.md).
