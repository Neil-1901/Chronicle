# Application screenshot checklist

The current screenshots under `evidence/screenshots/` are supplied forensic-tool exhibits, not screenshots of Chronicle. Capture the following from the actual running application after generating the network practice report. Do not substitute mockups or the tool exhibits.

Save the genuine application captures in this folder:

1. `application-overview.png` — network practice case, investigation scope and case separation.
2. `evidence-ledger.png` — capture size/hash and its current-run comparison caveat.
3. `network-examination.png` — selected frame, endpoint/timestamp details, source links, and decoder note.
4. `timeline-source-trace.png` — selected packet observation with capture/frame reference.
5. `correlation-findings.png` — CORR-004 request/response basis and its informational limitation.
6. `case-dossier-autopsy-exhibit.png` — registered screenshot with missing structured-source warning.
7. `investigation-report.png` — network-case report summary and export controls.
8. `glasshouse-validation.png` — separate synthetic case and a source-linked lead.
9. `evaluation-results.png` — current automated test result and evaluation limitations.

Before capture, run the steps in `docs/demo-script.md`. Keep the browser viewport and zoom consistent. Include no personal browser data in the capture.
